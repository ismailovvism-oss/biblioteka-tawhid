# supabase/ — бэкенд (слой L5)

Файлы бэкенда «Библиотеки Таухид»: аккаунты, приватные/платные книги, подписки.
Проектное обоснование и модель — в `../BACKEND.md`.

| Файл | Что |
|---|---|
| `schema.sql` | Миграция: таблицы, RLS-политики, приватный Storage-бакет. Идемпотентно. |
| `config.js` | Публичные параметры проекта (URL + anon key). Коммитить можно — не секрет. |
| `client.js` | Тонкий клиент на голом `fetch` (auth/rest/storage). **Пока не подключён** — фаза 1. |

## Настройка (делает автор в своём аккаунте Supabase)

1. **Создать проект** на [supabase.com](https://supabase.com) (free-тариф).
2. **SQL Editor → выполнить `schema.sql`** (вставить целиком → Run).
3. **Authentication → Providers → Email:** включить; **выключить публичную регистрацию**
   («Allow new users to sign up» = off) — регистрация закрытая (только владелец).
4. **Authentication → URL Configuration:** прописать адрес приложения в **Site URL** и
   **Redirect URLs** (нужно для возврата магик-линка).
5. **Settings → API:** скопировать **Project URL** и **anon public key** → вписать в
   `config.js`.
6. **service_role-ключ никуда не коммитить.** Он нужен только локально для заливки приватных
   книг (`tools/upload-private.js`, фаза 2) и для Edge Functions (фаза 3) — задаётся через
   переменную окружения / секреты Supabase, не в репозитории.

## Что уже готово и что дальше

- **Фаза 0 (эта):** схема + изолированный клиент + этот README. Кода, влияющего на работающую
  читалку, **нет** — `client.js` ещё не подключается в `index.html`.
- **Фаза 1:** подключить `config.js`+`client.js`, добавить UI входа (магик-линк) и обёртку
  каталога (публичные ∪ мои книги). Делается после шагов настройки выше.
- **Фаза 2:** `upload-private.js` (заливка приватной книги в бакет) + приватный путь чтения в
  `contentProvider`. Это закрывает цель — приватное чтение онлайн.
- **Фаза 3:** подписки (Edge Function + вебхук платёжки).

Безопасность: доступ решают RLS-политики в БД, а не приложение. anon key — публичный;
service_role — секрет и только на сервере/локально. Подробности — `../BACKEND.md`.
